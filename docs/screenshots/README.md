## Privacy edits

The built-in image editing tool applied opaque location masks to the Front, top/bottom split, and phone screenshots. The left/right, factory settings, and setup captures contained no visible location text and are unedited. Edited images can be resized by the image tool.

The redaction prompt used for each edited screenshot was:

> Apply only privacy redaction. Cover the GPS/location and measurement watermark with solid opaque dark rectangles. For radio captures, keep the existing REVERSE, SPLIT, and LINK buttons visible. For the phone capture, cover location text in both the FRONT DVR and REVERSE images. Preserve the UI layout, labels, recording indicator, and camera content. Do not add promotional graphics or combine screenshots.

Every published image was visually checked for readable coordinates and connection credentials before upload.
